# Privacy and Data Handling

sign-board 不是云端服务，也不会替部署者决定数据保存多久。部署者是活动数据的管理责任方，应在活动开始前完成告知、授权和删除安排。

## 收集内容

当前提交可以包含：

- 参与者填写的署名；
- 手写签名的坐标轨迹；
- 提交时间；
- 用于限流的设备标识哈希；
- 管理员审核状态和导出数据。

手机页面不会要求单位和寄语，服务端也不会保留这些字段的客户端输入。

## 展示和导出

署名和笔迹可能实时出现在公开大屏，并包含在管理员 CSV、PNG 和 ZIP 导出中。活动方应在二维码旁或现场说明中明确告知：提交即表示签名会用于现场展示和约定的归档用途。

## 部署者责任

- 使用 HTTPS，避免手机到服务器的传输被窃听；
- 限制管理员和监控令牌的接触范围；
- 不把导出包提交到 Git 或公开存储；
- 规定活动数据的保留期限；
- 提供参与者的更正、撤回或删除处理方式；
- 活动结束后备份、导出和删除数据；
- 对背景图、字体和活动品牌取得必要授权。

这份文档是技术说明，不替代部署者所在地区适用的法律、学校政策或组织隐私审查。
